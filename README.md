# CityPulse — Smart Outing Advisor

CityPulse is a command-line tool that tells you the **best time to visit a place in Delhi/NCR** based on live weather, live AQI, predicted crowd levels, and the place's actual opening hours. It uses a trained Decision Tree model to predict crowd levels and combines that with real-time data to give you a personalised risk advisory.

---

## Features

- **Live weather and AQI** — fetches real-time temperature and air quality index
- **Crowd prediction** — ML model (Decision Tree) trained on 5,000 realistic data points
- **Opening hours awareness** — won't suggest visiting a mall at 9 AM or a monument at midnight
- **Custom time/day planner** — check "right now" or pick any hour and day of the week
- **Risk advisory** — Low / Moderate / High risk based on crowd + AQI + temperature combined
- **Tomorrow suggestion** — if today has no good slots, automatically finds the next best time
- **EDA pipeline** — full exploratory data analysis with 6 charts saved to `data/eda_plots/`
- **Before/After preprocessing stats** — mean, median, mode, std dev shown before and after cleaning

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/city_pulse.git
cd city_pulse
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Create your `.env` file

Create a file named `.env` in the project root:

```
AQI_API_KEY=your_aqi_api_key_here
WEATHER_API_KEY=your_openweathermap_key_here
```

Get free API keys from:
- AQI: https://aqicn.org/api/
- Weather: https://openweathermap.org/api

> **No keys?** The app still runs — it falls back to AQI = 100 and Temperature = 30°C automatically.

### 4. Build the model (one-time setup)

Run these four scripts in order from the project root:

```bash
python scripts/generate_raw_dataset.py
python scripts/clean_data.py
python scripts/eda.py
python scripts/train_model.py
```

### 5. Run the app

```bash
python main.py
```

> Always run from the **project root** (`city_pulse/`), not from inside any subfolder.

## How It Works

### Data Pipeline

```
generate_raw_dataset.py
        ↓
  raw_crowd_data.csv   (5,000 rows, intentionally messy)
        ↓
    clean_data.py
        ↓
 clean_crowd_data.csv  (encoded, null-free)
        ↓
   train_model.py
        ↓
  crowd_model.pkl      (Decision Tree, max_depth=8, class_weight=balanced)
```

### Features Used by the Model

| Feature | Description |
|---|---|
| `hour` | Hour of day (0–23) |
| `day` | Day of week (0=Monday … 6=Sunday) |
| `place_type` | Shopping=0, Tourist=1, Hybrid=2 |
| `popularity` | Low=1, Medium=2, High=3 |
| `area_type` | Indoor=0, Outdoor=1 |
| `peak_hour` | 1 if hour in [17, 18, 19] else 0 |
| `weekend` | 1 if Saturday or Sunday else 0 |
| `temp_level` | 0=Cold(<20°C), 1=Comfortable(<32°C), 2=Hot(≥32°C) |

### Risk Calculation

Risk is crowd-first — AQI and temperature act as modifiers:

| Crowd | Base Risk | Escalates to High if… |
|---|---|---|
| Low | Low | AQI > 150 **and** temp > 35°C |
| Medium | Moderate | AQI > 200 **or** temp > 40°C |
| High | Moderate | AQI > 150 **or** temp > 35°C |

### Opening Hours Logic

Each place in `places.csv` has `open_hour` and `close_hour`. The app:
- Filters out time slots that fall outside the place's hours
- Returns a `🔒 Closed` message if a custom time is outside operating hours
- Only scans open slots when looking for the best time today or tomorrow

## Preprocessing Summary

`clean_data.py` runs in 7 steps and prints a detailed before/after comparison at each stage:

1. **Raw audit** — shape, dtypes, null counts per column
2. **Text cleaning** — fixes typos like `"mon"`, `"SHOPPING"`, `"high"` → canonical values
3. **Numeric stats** — prints mean, median, mode, std dev, min, max **before and after** filling nulls
4. **Feature engineering** — derives `peak_hour`, `weekend`, `temp_level`
5. **Encoding** — converts all text columns to integers using saved label maps
6. **Column selection** — drops raw `temperature` (replaced by `temp_level`)
7. **Final summary** — retention rate, crowd balance, clean sample

## Model Performance

- **Algorithm:** Decision Tree (max_depth=8, class_weight=balanced)
- **Dataset:** 5,000 synthetic samples based on Delhi/NCR crowd patterns
- **Train/Test split:** 80/20 with stratification
- **Accuracy:** ~61% (3-class: Low / Medium / High)

The model is intentionally simple and interpretable. Accuracy can be improved by using a Random Forest or adding more training data.

---

## Notes

- The dataset is **synthetically generated** to mirror real Delhi/NCR patterns (IMD temperature ranges, weekend peaks, place-type interactions). It is not sourced from a live database.
- API fallback values are `temperature = 30°C` and `AQI = 100` when keys are missing or invalid.
- Place name input is **case-insensitive** — `india gate`, `India Gate`, and `INDIA GATE` all work.
- Run all scripts from the **project root**, not from inside `scripts/` or `logic/`.
